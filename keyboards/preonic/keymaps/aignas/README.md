Ergonomic Dvorak Keymap
========================
An ergonomically optimized Dvorak keymap for the grid-layout Preonic

- Setup for qmk is [here](https://docs.qmk.fm/#/newbs_getting_started).
  ```bash
  qmk setup
  qmk flash -km aignas -kb preonic/rev3
  ```

Modes
----------

#### Dvorak

> Base layer

- All alphanumerics and symbols available on the base layer

----------

#### Game

> QWERTY layout for use with games or number entry

- Standard QWERTY layout
- Integrated right-hand numpad in phone layout

----------

#### Function (Raise)

> Functions and mode switching

- Turns on the arrow cluster, with nav cluster ubove (Home, Page Down, Page Up, End)
- Reset key at lower left (=)
